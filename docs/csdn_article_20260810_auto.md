# 我让 AI 每天 8 点自己写日报：一套基于 MCP 工具的自动化实战

## 写在前面

每天早上 8 点，我的手机准时弹出一条推送：今日日报已生成。

打开一看：昨日全球市场行情、今日重要新闻、我的项目进度、今日待办——**排版整齐，要点齐全，就像助理熬夜写好的。**

但写它的不是人，是我的 AI Agent。它每天自动执行一套流程：查行情 → 抓新闻 → 读项目文档 → 汇总成文 → 推送给我。

这篇文章分享这套自动化是怎么搭的。核心不是某个神秘工具，而是一个 2026 年开发者必须知道的概念：**MCP（Model Context Protocol）——让 AI 拥有"手"的协议。**

## 一、日报自动化，需要 AI 会什么

先拆解一份日报的生成流程：

```
① 查行情    → 需要"查股票/汇率"的能力
② 抓新闻    → 需要"读新闻源"的能力
③ 读文档    → 需要"读本地文件"的能力
④ 汇总成文  → 需要"大模型推理"的能力
⑤ 保存推送  → 需要"写文件/发消息"的能力
```

传统 LLM 只有第 ④ 项能力——它能写，但拿不到数据。

没有工具的 AI 写日报，只能编。有了工具的 AI 写日报，全是真数据。

## 二、MCP 是什么（30 秒版）

MCP 是 Anthropic 2024 年底开源的协议，现在 Cursor、Claude、VS Code、Dify、Coze 全部原生支持。

一句话：**MCP 把"工具"标准化，让 AI 可以调用外部能力，就像人用手一样。**

工具可以是：
- 查天气、查股票、查汇率（数据类）
- 读文件、写文件、读数据库（文件类）
- 网页抓取、截图、OCR 识别（网页类）
- GitHub 操作、发消息、调用 API（行动类）

## 三、实战：我的日报流水线

我用的是一套聚合了 127 个 MCP 工具的网关（地址见文末），一个地址全接入。日报流程用到了其中 5 类工具：

### 第一步：抓新闻（news 工具）

```json
调用：news_get_news
参数：{"source": "ithome"}
结果：IT之家今日头条 20 条
```

我配置了 IT之家、cnBeta、少数派、阮一峰、V2EX 五个源，一次调用全拿到。中文科技圈动态，一条不落。

### 第二步：查行情（market 工具）

```json
调用：mkt_get_stock_quote
参数：{"symbol": "AAPL"}
结果：最新价、涨跌幅、成交量
```

股票、加密货币、汇率、天气，真实数据接口直出。日报里的"市场快讯"部分全靠它。

### 第三步：读项目文档（fs 工具）

```json
调用：fs_read_file
参数：{"path": "/projects/daily/todo.md"}
结果：今日待办清单
```

AI 直接读我的待办文件，把"我昨天干了啥、今天要干啥"写进日报。

### 第四步：汇总成文（LLM 推理）

把上面三部分数据 + 提示词交给大模型：

> "你是日报编辑。基于以下数据生成今日日报：新闻要点 5 条、市场快讯 3 条、项目进度摘要。语言精炼，分节排版。"

### 第五步：保存 + 推送（fs + 消息工具）

```json
调用：fs_write_file
参数：{"path": "/projects/daily/2026-08-10.md", "content": "..."}
```

存成 Markdown 文件，再通过定时任务推送到我的手机。

## 四、整个过程，AI 是主角

你可能注意到了：**上面的每一步，AI 都是自己完成的。**

我只需要在每天早上 8 点给 Agent 发一句：

> "执行日报流程"

剩下的——查什么、调哪个工具、传什么参数、怎么汇总——全部由 Agent 自己决策。这就是 MCP 的威力：**不是人指挥工具，而是 AI 自己调用工具。**

## 五、普通人怎么上手

如果你也想搭类似的自动化，三条路：

**路线 A：用现成客户端（零门槛）**

装 Cursor 或 Claude Desktop，配置 MCP 地址（Streamable HTTP 类型，填入网关 URL + Token），然后在对话里说"帮我查一下今天的新闻热点"——AI 会自动调用工具。

**路线 B：用工作流平台（低代码）**

Dify / Coze 里拖拽节点：定时触发 → 工具调用 → LLM → 输出。可视化搭流水线，不用写代码。

**路线 C：自己写脚本（开发者向）**

MCP 网关完全兼容标准协议，用 Python/Node 的 MCP SDK 直接调：

```python
from mcp import ClientSession

async with ClientSession(url="https://mxt-api.cn/mcp/gateway/") as session:
    result = await session.call_tool("mkt_get_stock_quote", {"symbol": "AAPL"})
    print(result)
```

## 六、还能自动化的场景

日报只是冰山一角。同样的套路，可以复制到：

- **周报月报**：汇总本周代码提交 + 会议纪要 + 项目进度
- **竞品监控**：每天抓竞品官网/新闻，生成变化简报
- **舆情监控**：热榜 + 关键词搜索，异常波动自动告警
- **文档流水线**：截图 → OCR → 转 Word → 归档
- **数据看板**：定时查数据库 → 生成图表 → 发群
